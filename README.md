# Бухгалтерский тест

Простой автономный сайт с 30 тестовыми вопросами и 6 практическими заданиями (100 баллов).

## Публикация на GitHub Pages

Загрузите в корень репозитория файлы `index.html`, `styles.css`, `app.js`, `exam-data.js`, `favicon.svg` и `favicon.ico`. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите ветку `main` и папку `/(root)`; сохраните настройки. Адрес сайта появится в разделе Pages.

## Как работает проверка

1. Все 30 вопросов и 6 задач обязательны. За тестовую часть начисляется до 30 баллов, за практические задания — до 70.
2. После проверки каждого ответа сразу показывается правильный ответ и пояснение. Исправить подтверждённый ответ нельзя, даже при возврате назад.
3. В вопросе №17 засчитываются один или два ответа из А, Б, В. После проверки отображается обязательное пояснение об неоднозначности вопроса.
4. Практические задания разбиты на проверяемые этапы; баллы рассчитываются автоматически. Числовые ответы принимаются с запятой или точкой, допустимое расхождение — в пределах одного тенге.
5. На финальном экране — общий балл, результаты разделов, затраченное время и разбор ответов.

Данные не отправляются на сервер; сторонних сервисов и внешних подключений нет. Для запуска без публикации достаточно открыть `index.html` в браузере.

Важно: отдельные исходные формулировки неоднозначны. В тесте для таких случаев указаны допущения. Это тренировочный тест, не официальная аттестация.

## Иконка вкладки

В `favicon.svg` и `favicon.ico` находится значок, повторяющий эмблему в шапке сайта. При обновлении уже опубликованного сайта замените `index.html` и добавьте оба файла иконки в корень репозитория. Если браузер показывает старую иконку, перезагрузите страницу без кеша (Ctrl+F5).
